02

Key Achievements By Theme

Highlights grouped by focus area, kept concise.

Infrastructure

Capacity, reliability, and throughput at scale.

  • 5.3 PB of research data managed, +23.26% YoY
  • 4,692 CPU cores and 43 TB memory deployed
  • 28 GPUs delivering 748.5 TFLOPS
  • 99.9% uptime on critical systems (2.6 h downtime)
  • 10,166,338 Slurm jobs processed

Research enablement

Tools and platforms that accelerate discovery.

  • 90 active web apps supported for researchers
  • 227 unique compute users (+11.27% YoY)
  • CUDA-accelerated workloads across 211,968 cores

Security & compliance

Zero breaches, continuous vigilance.

  • 0 security breaches; 100% compliance maintained
  • 714 security trainings completed
  • 457 phishing emails reported by staff

Service excellence

Responsive, well-rated support.

  • 3,790 support tickets resolved (11.35/day)
  • 1,081 requests via IT service catalog (+15.5% YoY)
  • 5/5 overall user rating (+0.02 from 2024)
